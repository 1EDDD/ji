# Nuvio AI

Private AI-enhanced addon for Nuvio.

## v0.1

- Stream condenser
- Duplicate reduction
- Release quality scoring
- Optional Gemini ranking
- Provider-agnostic upstream stream addon

## Security

Do not put GEMINI_API_KEY in this repository or in client-side code.
Set it as a server environment variable on your hosting provider.

## Run

npm install
npm start

Manifest:
http://localhost:7000/manifest.json

See .env.example for configuration.
